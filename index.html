Built for the whole pipeline

From a single clip to a folder of lectures, VTT handles the boring parts so you can read the transcript, not fight the tool.

Runs fully offline

Whisper does the transcribing locally — no cloud API, no rate limits, no audio ever leaves your machine.

Real timestamps

Genuine .vtt and .srt files with per-segment timing — not a single block of raw text.

Batch & YouTube

Hand it a folder and it works through every clip, or drop in a YouTube link and skip the download step.

~100 languages

Auto-detects the spoken language, or pin it yourself with -lang for faster, more reliable results.

CPU or GPU

Pick a model size and device that fit your machine, from a quick tiny pass to a large-v3 run on CUDA.

One binary, one command

Install with pip, run vtt_run. No config files, no accounts, nothing to set up first.

Install & reference

Available on PyPI, or clone the repo and run it straight from source.

install
$ pip install video-to-text-vtt
$ pip install "video-to-text-vtt[youtube]" # optional, for URL input
-lang, --languageLanguage code (e.g. fa, en) — omit to auto-detect
--modeltiny · base · small · medium · large-v3
--deviceauto · cpu · cuda
--formatvtt · srt · txt · all
--offset / --durationTranscribe just a slice of the file, in seconds
-o, --outputOutput file, or output folder when batching
